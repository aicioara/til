# Fast Open File macOS

In [Keyboard Shortcuts](macos/keyboard-shortcuts.md), I shared that <kbd>⌥</kbd> + <kbd>⌘</kbd> + <kbd>space</kbd> shortcut opens finder. However, by default, this does not look like finder. There are two settings that one needs to change from the default.

1. Show sidebar

`View` -> `Show Sidebar`

2. Show path bar

`View` -> `Show Path Bar`
